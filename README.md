## 📌 Giới thiệu

**IOT_AI** là hệ thống tích hợp giữa **IoT** và **Trí tuệ nhân tạo (AI)**, nhằm **giám sát**, **phát hiện**, và **ứng phó kịp thời với hỏa hoạn**.  
Dự án hướng đến mục tiêu:
- Tự động phát hiện đám cháy qua hình ảnh, cảm biến nhiệt/khói
- Cảnh báo người dùng thông qua ứng dụng
- Kích hoạt hệ thống chữa cháy tự động
